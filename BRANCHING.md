# CampusBite - Branching Strategy

## Main Branch
main - Stable production code.

## Development Branch
develop - Integration of features.

## Feature Branches
feature/login
feature/order-history
feature/admin-menu
feature/admin-orders

## Workflow
1. Create a feature branch.
2. Develop and test the feature.
3. Commit changes.
4. Push the branch to GitHub.
5. Create a Pull Request.
6. Merge into develop after review.
